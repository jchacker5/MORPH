\topic{Calibration sensitivity.} Every scaled adaptive model chose one pass on every test case with the registered threshold grid. The three accuracy differences therefore cannot establish useful input-dependent depth. A post-hoc finer threshold search produced variation. Using only the original stored hazards, we calibrated on the first half of each archived test set and scored the second half. The gains against the fixed frontier at the three sizes were $-6.12$, $-2.97$ and $-7.78$ pp. Because this analysis was designed after the original tests, it is exploratory. Five of twelve diagnostic checks changed some predictions when discarded checkpoints were retrained with their archived seeds. The main tables use the original predictions; the companion data distinguish same-weight cached comparisons from retraining.

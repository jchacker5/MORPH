# Code of Conduct

MORPH follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be direct about results and kind to people. Disagreement about a finding is welcome. Critique the method, not the person.

Report unacceptable behavior privately to the maintainer through the contact options on [Joseph Defendre's GitHub profile](https://github.com/jchacker5). Reports are handled confidentially.

# Independently held-out checkpoint qualification

The 2,400-update seed-17 adaptive model solved 87.85% of the original follow-up ID pool, and the two-pass fixed reference solved 96.18%. For one engineering qualification, train these two architectures from scratch with the same seed 17 and fresh, identical mini-batches for 8,000 updates, batch 24, Adam with unit gradient clipping, peak 0.00045 and the longer follow-up warmup/cosine rule. Save both checkpoints regardless of outcome. Use separate test seeds and a separate threshold-development seed; 384 test examples per ID length and 192 per shifted condition. Keep threshold calibration blinded to all test examples. No selection across checkpoints.

Qualify each checkpoint for the specified input distribution only if its pooled ID exact accuracy is at least 95% and its lower two-sided 95% Wilson binomial bound is at least 93%. Additionally require at least 90% on each of the four shifts to call it qualified for the defined distribution shift suite. A single model can demonstrate a runnable artifact but does not establish between-seed effects. This separately reported checkpoint exercise does not change the predeclared main comparisons.

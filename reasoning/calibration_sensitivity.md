# Exploratory sensitivity to halt-threshold grid resolution

The original 0.001 grid was prespecified and remains primary. During the longer 10M/30M fits, observed native hazards clustered very close to zero or one. A coarse search can then tie always-stop with never-stop and return always-stop under the prespecified tie rule. Test whether refining only the calibration search changes the achieved budget or fixed-frontier result.

For the 2,400-update small models and 160-update scaled models, use the same dev drawings, checkpoint, and mean-2.5-pass objective. Consider every distinct allowed threshold at which the empirical hard-exit assignments change. Resolve ties toward the lowest threshold as before. Select no parameter on the final set. Evaluate ID held-out draws at the frozen refined threshold via actual conditional execution; compare with the existing fixed envelopes, stratified permutations, and raw 0.5 control. Retain mean depth, achieved FLOPs, accuracy and compact-vs-cache discrepancies. Where checkpoints were already discarded, replay identical training and compare the original-threshold hard predictions and hazard probabilities on ID data; report discrepancies. This is a post hoc sensitivity reusing the published test samples, not a fresh confirmatory test.

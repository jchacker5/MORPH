# MORPH mechanism probes, protocol v1

Registered locally before model training. The run records a SHA-256 digest of this file. The probes use deliberately small components trained from scratch on generated supervised prediction problems. They test individual mechanisms independently of the Transformer and joint-controller experiments.

## Shared analysis

Use paired initialization/data seeds 11, 29 and 47, new online training batches for a fixed number of updates, and a separate deterministic test stream with 2,048 examples per condition and seed. Do not tune on test results or replace an unsuccessful seed. Estimate uncertainty from paired seed-level metric differences using a two-sided Student t interval, df=2. Ranges crossing zero are inconclusive. Accuracy and routing summaries are secondary unless explicitly designated primary. Source code records the exact generators. Train with MLX on CPU and evaluate hard choices. Timing, wherever present, concerns the indicated reference implementation on this machine.

## 2. Token grouping

A causal synthetic record language uses a prefix of 16 (symbol, value) records, a query symbol, then a value token to predict. Twelve symbols belong to four hidden families of three (fixed scrambled assignment). Each episode samples four independent uniform values in 0–3, one per family. The model receives symbols, values and the query, never the family labels. Query symbols and record symbols are independent uniform draws. Only query-value positions contribute to conditional perplexity; there is no natural-language PPL claim. A per-slot key histogram and value histogram summarize the observed prefix. A trainable key-affinity reader scores slot addresses, and reads mixtures of slot value frequencies with additive smoothing. All arms use the same reader. Learned writes share a trainable 12 by K assignment table, soft during training and argmax at test. Controls use balanced random type mappings, adjacent positional segments, and interleaved fixed stride. Include an uncompressed one-record-per-slot reader and a family-oracle writer. Train each reader/writer for 300 steps of 64 episodes with Adam; run slot budgets K=2,4,8 for all four comparisons. Primary: learned minus strongest non-oracle compressed baseline in test log loss at K=4. Compare all curves and report true-family versus hard-write adjusted Rand index. ARI pools records, allowing positional baselines to participate. Overwrite every suffix token after the query and verify equal predictions. The compression ratio counts record slots only; include histogram payload explicitly.

## 3. Expert routing

Each balanced task comes with one of two learnable task-marker synonyms. A and B are four-way discrete inputs and C is a binary structural flag. Four tasks ask for (A+B) modulo four, the next closing bracket type in a two-open-bracket stack (B if inner still open, else A), copying A, and a fixed substitution of B. The entire input is available to each router and expert. All arms have four two-layer MLP experts of hidden width 24. Learned risk routing optimizes expected per-expert cross-entropy under a linear softmax router, with a usage regularizer, then dispatches top one at inference. Compare an input-independent uniform random expert, all four experts with averaged logits, and conventional Switch-style top-one routing with selected-probability-scaled output and load balancing. The expected-risk objective evaluates every expert during training; comparisons match data and updates. Train all arms for 500 steps of 96 examples at Adam LR 0.012; balance coefficient 0.05. Primary: exact-match accuracy and number of active scalar parameters versus standard top-one. Secondary: mutual information of expert and task, task-expert frequency matrices, per-task accuracies, and forced-cyclic-expert counterfactual accuracy. Report held-out inputs new from the same finite task support, which can overlap training examples. Do not infer abstract reasoning.

## 4. Selective memory

A pre-stream color cue is known; unique key/value/color records arrive; a post-stream query selects a key uniformly from four cue-matching records. Values are independent uniform integers 0–15. Score candidates using cue, record color, their outer product, and position; an MLP learns priorities through answer likelihood under a smooth capacity approximation. It receives no explicit retention labels. Training lengths are 32, cue probabilities [0.4,0.4,0.1,0.1], with relevant entries placed uniformly. Train for 250 steps of 64 episodes per seed/capacity, Adam LR 0.02. Test IID, cue shift (uniform on rare colors), recency shift (all relevant records in oldest quarter), both shifts, and both shifts at length 96. Compare full storage, fixed-window recent items, fixed uniformly spaced entries, learned streaming top-K, and a deterministic cue-matching reference. Evaluate K=4 and 8. Primary: exact recall at K=4 under both shifts at length 32, versus strongest capacity-matched non-oracle deterministic policy. On a miss always predict zero; also report key-hit rate. Report retained cache-array bytes separately from trainable parameter count and transient tensors, plus median streaming CPU microseconds per episode over three complete measurement blocks. Group priorities using each episode's colors, then permute the resulting scores across positions to test the value of relevance alignment.

## Constraints

Synthetic data use no network downloads. Comparisons and iteration counts are frozen; unexpected failures in these probes are reportable evidence. No method is selected by test. The stochastic repeat unit is a full training seed, not a token or a query. These probes do not establish value in real-world language systems.

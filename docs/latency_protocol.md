# Engineering timing check
After study training finishes, benchmark the saved 118K five-minute adaptive and 30M 2048-step seed-11 models on the original test contexts. This is a descriptive systems measurement, written before timing those checkpoints under quiet project load. Run all modes on the same weights with batch 1 and 16. Compare the actual adaptive dispatch with forced depths 1, 2 and 4; these forced modes measure execution cost and do not retrain or compare predictive quality. Use 6 warmups per combination followed by 48 timed rounds per mode in deterministic shuffled order within each scale and batch. Preload inputs, synchronize logits every call, return the median/p90 batch latency and median latency divided by batch size. Report average actual passes, active and peak MLX allocations. Other non-study processes on the laptop may run. Run once without changing settings in response to results.

# MORPH language experiment protocol
Owner: Joseph Defendre. Freeze before viewing validation or test losses. Separate natural-text companion to Experiment 1.
## Data and outcome
Use the raw bytes of Karpathy's tiny Shakespeare corpus from char-rnn commit 6f9487a6fe5b420b7ca9afb0d7c078e37c1d1b4e. Contiguous byte splits at floor(.8 N) and floor(.9 N). No context may cross a boundary. Score next byte on final 48 positions of each 64-byte context. Validation and test windows are chosen deterministically with stride 48 so the scored targets do not overlap. Use 256 byte classes and report bits per byte (BPB) and byte perplexity. The primary contrast is hard adaptive minus fixed two-pass BPB, accompanied by actual mean depth and estimated cost. Evaluate every full test window, with a 192-window evenly spaced validation sample for search. Report bigram and interpolated order-three history predictors trained on training bytes only. The limited-use criterion is a reloadable text generator plus at least 0.10 BPB gain over the smoothed bigram on held-out bytes; report the stronger count model too. Dialogue/instruction ability is outside this test.
## Models and accounting
All neural models use a 96-wide, 4-head causal self-attention block with expansion 3, sinusoidal positions, shared parameters across recurrent passes, a tied embedding/output matrix and up to four passes. A learned hazard observes only the first 16 input positions at each step. A single exit applies to all 48 scored positions. Train using expected cross entropy over exits plus a per-pass cost; force the fourth exit. At inference exit when a hazard exceeds a fixed threshold (0.5), using real conditional execution. Baselines include a shared one-, two- and four-pass model, and uniform random depth. Explore extra threshold values as a labeled sensitivity analysis. Compare shared initialization and training windows for a given seed, count examples/tokens, estimated matrix FLOPs (2 per MAC, 3x forward for backward + forward), optimizer steps, synchronized elapsed time and observed batch-1 timings. Cost estimates exclude elementwise ops, I/O and optimizer updates. Baselines and adaptive can have unequal training FLOPs; add a longer two-pass comparator whose step count is fixed by estimated training FLOPs. Primary analysis is paired across three fresh seeds (11, 23, 37); report each and a two-sided 95% paired Student interval. Treat other tests as descriptive.
## Autoresearch track
Adapt Andrej Karpathy's program at commit 228791fb499afffb54b46200aca536f79142f117: fixed evaluation harness, wall-time-limited trials, validation objective, append-only keep/discard results with hypotheses. Use a 30-second synchronized training window per trial in place of upstream's 300 s. Development seed 7 is disjoint from final seeds. Optimize hard validation BPB with a penalty of 0.08 BPB per mean pass above 2, accepting a decrease exceeding 0.005. Start with LR .002, pass cost .02, gate bias 0.0. Propose one-factor edits to the incumbent, recording the hypothesis before each run; stop at three consecutive discarded candidates after at least four trials, or eight total trials. Bound trials independently of positive or negative conclusions. Freeze the incumbent before touching final outcomes. Confirmation uses 320 optimization steps with batch 16 for every model except compute-matched two-pass. Use the selected learning rate for all architectures. Run fixed four-pass a second time with LR .002 if selection changes LR, to expose optimizer sensitivity. Save the adaptive seed-11 model without selecting by outcome. Verify causal invariance, hard/dense policy parity, reload and generation.

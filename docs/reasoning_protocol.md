# MORPH reasoning study protocol

Author: Joseph Defendre. Local protocol registered before the first model fit. The SHA-256 and UTC creation time are archived with the results. All random streams for development, final testing, and training differ. These decision rules cover experiments 1, 6, 7, and 8.

## Task and data

Generate a fair initial bit, apply independently sampled unary Boolean instructions (identity, NOT, set-zero, set-one), and predict the final bit. Choose instruction slots uniformly without replacement in the sequence interior, in execution order. Unused positions contain independent distractor symbols. Initial bit and final query occupy fixed endpoints. The explicit instruction count is a proxy for compositional depth; reset instructions can shorten the effective dependency chain. Chance is 50%. For the main study, train on lengths 32, 64, 128, and uniformly sampled counts 1–3. Evaluate a balanced length mixture on the same distribution, then change length only to 256, 512, 1024, and count only to 4–6 at length 64. Also evaluate train-range counts at length 64 as the direct control for the count shift.

## Models, budgets and decisions

Train all systems from scratch. Use a causal decoder with rotary positions, pre-normalized attention/MLP, a shared output readout at the final query and up to four passes. Main pilot width 64 and FFN expansion four. Recurrent fixed-depth models at 1, 2, 3, 4 passes, input-independent random-depth recurrent model, untied four-layer approximately parameter-matched decoder at width 32, and MORPH. The learned hazard takes the final query state and is trained by minimizing the expected cross-entropy across all possible exits plus 0.012 nats per expected pass; the last exit is compulsory. Fix optimization at Adam 0.002, 120 updates of batch 16 per architecture per seed, no validation stopping. The three paired training seeds are 17, 29 and 43. All methods share training arrays and final evaluation examples across seeds. Random baseline draws one uniform depth per minibatch for stochastic training and independently per example at evaluation.

Run fixed-width/fixed-depth four and MORPH at widths 896, 1600 and 2880 (roughly 10M/30M/100M actual trainable parameters) with paired initialization/data, the same seeds, Adam 0.0003, BF16 backbone, sequence length 32, batch two, counts 1–3. This is a short-horizon engineering replication that changes width and per-size FLOPs. Select the common number of updates by timing training only, before examining scaling evaluation: plan 16 per fit, reduce to 8 if a width-2880 training step takes more than 2 seconds, or 4 above 5 seconds. Log throughput and exact example counts. Evaluate 64 test examples per model in batches of 4 and calibrate using 64 different development examples. Report actual executed budget at each size. The fixed-four shared backbone closely matches both parameter count and training operations of adaptive four-exit training. Use the shared-four checkpoint nearest the learned model under the analytical training FLOP model and record residual mismatch. FLOPs exclude elementwise ops and optimizer, and count dense square attention matrix products with two FLOPs per multiply-add, not measured chip instructions. Training FLOPs use three times the forward matmul estimate. Iso-training comparisons outside 1% residual are identified as unmatched.

## Tests and inference policy

For the main study use 192 independent final draws per ID length and 96 per shift condition, shared across models. Use distinct 96-example dev sets per ID length. A common halt threshold is calibrated on development data to mean 2.5 passes, using a grid over [0,1] and nearest attainable mean depth; ties resolve to the lowest threshold. Freeze this value before all final evaluations. Report the raw 0.5 hazard threshold as a secondary diagnostic; the primary is the calibrated policy. Record hard exits and compare these to physically compacting the surviving batch during inference. At ID compute a budget frontier from all convex mixtures of fixed inference policies, comparing MORPH accuracy to the best baseline feasible at its aggregate FLOPs; if no fixed point is feasible report no comparison. The baseline frontier uses models designated fixed (including the narrower untied decoder). Primary effect is the paired adaptive-minus-frontier accuracy in percentage points. Report seed-wise results and descriptive 95% t intervals across three independent initializations on a fixed test set. Limited seed count and shared finite test draws restrict interpretation.

Experiment 6 records exit histograms, association of depth with independently defined instruction count (Spearman, null for constant), and accuracy changes under forced depth 1/2/3/4 and 32 prespecified permutations of the observed exit allocation within each sequence length. Permutation controls preserve the depth histogram and aggregate arithmetic. Experiment 7 applies the frozen controller without retraining/recalibration. Report distribution-specific accuracy, average depth, and per-example cost. Evaluate whether main benchmark performance can exceed chance and whether the learned model sustains useful performance over shifts; do not infer natural-language usability.

## Reproduction and limits

Export per-run metrics, configuration, parameters, training and inference arithmetic, inference timing and process peak allocated MLX bytes. Peak allocation may include training/optimizer unless reset for inference. Wall times are machine-specific and may include concurrent local work. Preserve an independently loadable representative seed-17 pilot checkpoint for the trained adaptive model. Scientific conclusions include negative results, controller collapse, and undertraining. No tuning against final evaluations.
